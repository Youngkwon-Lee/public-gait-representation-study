# Management workflow

- This public GitHub repository is the versioned source for portable research code, reviewed methods and aggregate results.
- The existing private Second Brain vault carries a candidate/review research-state note and links. Do not change its visibility or silently promote the note to canonical.
- A restricted Google Drive project folder is the backup destination for source archives, analysis outputs and provenance. Its private URL is intentionally not published here.

These are separately verified stores, not an assertion of automatic continuous synchronization. No recurring ingestion, automatic deployment, publication bot or CI schedule is installed by this repository.

For a new experiment:keep original inputs immutable; use a new output directory; capture source and code hashes; run numerical/semantic checks; publish only reviewed aggregate changes; append the private research-state/backup index; verify each destination independently. Record pending and completed states separately.
