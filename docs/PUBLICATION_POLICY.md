# Publication and privacy policy

## Public repository
Only portable source code, tests, aggregate research results, source URLs/hashes and reviewed methodological notes belong here. Public participant-coded raw files, clinical row tables, machine-specific logs, model weights/XML, credentials and internal infrastructure identifiers are not part of this initial publication.

Private clinical data is out of scope and must never enter this repository or its fixtures. Do not add a private backup URL or vault location to a public commit.

## Private storage
Raw public-source archives and full machine-specific execution receipts remain in controlled local/private-backup storage. Second Brain stores a small candidate/review record and links; it is not a store for raw records or runtime credentials. A candidate main publication is not canonical knowledge promotion.

## Before each push
Run tests, inspect git diff --cached, scan staged files for emails, credentials, internal IPs/hostnames and absolute personal/runtime paths, and verify no data/model/log files are staged. Recheck factual claims against the specific experiment, code version and environment.
